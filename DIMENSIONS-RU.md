# Измерения LL8 Extended

В сборке зарегистрировано 57 измерений. Сорок семь из них — места, где игрок может
стоять; остальные служебные: это рабочие пространства машин и площадки, на которых
сборка собирает подземелья. Ещё несколько миров создаются на ходу, поэтому в списке
зарегистрированных их нет.

Способы входа взяты из самих модов: теги рамок портала в `data/<мод>/tags/block/`,
рецепты предметов-активаторов и байткод классов портала. Там, где источник указан
как «механика мода», по коду это не подтверждено.

Названия предметов даны так же, как игрок видит их в игре с русским языком: если
русификатор название не перевёл, оно остаётся английским.

## Создаются на ходу

Эти миры не зарегистрированы заранее — они появляются, когда игрок их построит:

| Мод | Что создаёт |
|---|---|
| RFTools Dimensions | свои измерения через Dimension Builder (типы cavern, fixed_day, fixed_night, normal_time) |
| Applied Energistics 2 | Spatial Storage — пространственные ячейки |
| Ars Nouveau | измерение внутри банки (`ars_nouveau:jar`) |
| Linking Books | миры-возрасты по связывающим книгам |

## Что подтверждено чем

| Измерение | Источник |
|---|---|
| Подземный сад | `data/undergarden/tags/block/portal_frame_blocks.json` + рецепт `undergarden:catalyst` |
| Потусторонье | `OthersidePortalBlock$OthersidePortalShape` (армированный глубинносланец) + `WardenHeartItem.useOn` |
| Вечный звёздный свет | `data/eternal_starlight/tags/block/portal_frame_blocks.json` (резной пустокамень) |
| Тропики | `data/tropicraft/tropicraft/drink/pina_colada.json` — действие `tropicraft:portal`, время суток 12200–14000, `while_riding: tropicraft:chair` |
| Bumblezone | `tags/entity_type/dimension_teleportation/teleport_projectiles.json` — `minecraft:ender_pearl` |
| Шахтёрские измерения и Пустота | рецепты `jamd:portal_block`, `jamd:nether_portal`, `jamd:end_portal`, `javd:portal_block` |
| Комплекс | `ComplexPortalShape` и `PortalIgnition` (блоки железа), `PortalPower` (редстоун) |
| Захолустье, Окаменевший лес | `BackwoodsCanMakePortalProcedure`, `ThePetrifiedWealdCanMakePortalProcedure` |
| Новый мир | `UltimateSingularityItem` |
| Подземелья измерений | рецепты `recipe_item_blank_key`, `recipe_block_portal_keyhole`, `recipe_block_gilded_portal` |
| Глубины, Последнее тысячелетие | рецепты `depths_portal.json`, `last_millennium_portal.json` |
| Мир компактных машин | рецепт `personal_shrinking_device.json` |
| Космос | `stellaris:rocket`, `rocket_launch_pad`, модели ракет |

Imbrifer, Кукурузное поле, Убежище, Подземелье NeoVitae и порядок набора адресов
Stargate описаны по общей механике модов, а не по коду.
