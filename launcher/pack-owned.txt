# Files this pack owns outright.
#
# An instance is merged from the pack three ways, and a file that matches
# neither the pack's old copy nor its new one is taken for the player's work
# and left alone. That is right for a setting somebody tuned by hand and wrong
# for a file a mod rewrites on its own - such a file looks edited from the
# first launch, so nothing shipped here could ever reach it again.
#
# Everything listed below is written over instead. What was there is copied
# into the instance's conflicts folder first, as name.user-file, so a change
# somebody did mean can be put back. Keep this list to files the pack really
# decides: anything a player is meant to tune belongs outside it.

# Agritech generates these three from whatever is installed, and it generated
# them while Regions Unexplored and Oh The Biomes We've Gone were still here.
# Every line naming a block that no longer exists became an error while the
# recipe screen was built - about 8,900 of them in one launch - and the mod
# rewriting its own tables is exactly what made the corrected ones unreachable.
config/agritech/*.json
config/agritechevolved/*.json
config/agritechtrees/*.json

# The spider is back on its own settings, and this claim is how that reaches an
# instance that was tuned earlier: the file ships empty, the launcher writes it
# over, and the mod fills in its own defaults on the next read.
config/arachnomod-common.toml

# How fast an item slides between slots; the mod rewrites this file itself.
config/smoothswapping.json

# The backup schedule. SimpleBackups rewrites its config on start, so without
# this claim the incremental schedule shipped here would never reach a player
# whose instance already exists.
config/simplebackups-common.toml

# KubeJS writes this one itself the first time it starts, so the copy shipped
# here never reached an instance that already existed - and the HTTP and
# WebSocket server it opens on localhost:61423, which this pack has no use for,
# went on listening.
kubejs/config/web_server.json

# Immersive Optimization rewrites its config too, and it stamps a version into
# it, so an instance that has run once has a file that looks edited by hand.
config/immersive_optimization.json

# Sky Aesthetics generates both of these itself - which is why there are two
# spellings of one name - so the cleaned copies here would otherwise stop at
# the sync. Nothing in either file is meant for a player to tune: they name
# mods and dimensions this pack has, and one of those names was a mod it no
# longer has.
config/sky-aesthetics.json
config/sky_aesthetics.json
