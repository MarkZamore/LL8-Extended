# Every resource pack this build decides, and the order it belongs in.
#
# The order is the build. A later line sits above an earlier one where two packs
# redraw the same thing, so which of two packs is the one seen is decided here
# and nowhere else. The whole rule: the wider a pack reaches, the lower it sits.
# The Backwoods classic set is the ground for vanilla - blocks, items, entities,
# interface, particles, even the font - and Gray's Mob Overhaul sits above it for
# mobs; the mod packs sit on both, because each speaks for one
# mod and should win where it meets a base coat; then the build's own item,
# armour and family packs; and on top the packs that redo exactly one thing.
#
# Every pack here is locked the same way, by one list: its id is named in
# enable_builtin in config/global_packs.toml, and Global Packs gives every id it
# matches the same selection - (required, TOP, fixedPosition) - so the screen
# offers neither a tick to clear nor a handle to drag. "file/" is a pack shipped
# as a file in resourcepacks/, anything else is a pack that lives inside a mod's
# jar, and nothing but that distinguishes them any more: the mod compares the
# list against each pack's own id, whatever the pack is.
#
# Naming them here is what gives them their order. A required pack the selection
# does not name is only inserted at its default position, and they came out
# alphabetical back when this file did not name them all.
#
# The two marks are still part of this format and nothing uses them now. "?"
# hands an entry's on and off to the player and keeps only its place; "-" is
# the same thing shipped off, and both work by being ids left off that list.
#
# The villagers were the one slot that used them, and there is no slot left:
# Gray's Mob Overhaul brings the villager whole - model, textures, and the
# properties file that deals out its thirty-odd random skins. Nothing here
# overrides that file, so a second villager pack gets Gray's 128x128 skins on
# its own model however high it sits. Luigi broke that way and Thicc broke it
# the same way, so both are gone and the villagers are Gray's alone.
#
# The launcher holds all of this: every launch puts these entries back in this
# order and back on - all of them, while nothing here is marked. The player's own packs are never
# touched - not reordered, not switched off.
#
# The block before the Backwoods set is what the ground itself is painted on: what a mod
# generates or switches on for itself, and the packs that redraw only their own
# mod's blocks. These were the last entries a player could still drag about or
# switch off. Their order among themselves barely matters - nothing in the build
# redraws what they do - with one exception: tnp_resources says in its own
# pack.mcmeta that it must sit above Mod Resources, and it does.
#
# Two things are still the game's to place. vanilla is the ground under
# everything and the game keeps it there; the KubeJS packs are rebuilt every
# launch under names with commas in them, which no list of this shape can hold.
#
# What a mod offers as an older or plainer version of something the build
# already draws is handled two ways, and which way depends on one measurement:
# whether every file in it is redrawn by something that would sit above it. A
# pack where that holds is switched on at the very bottom, where it changes
# nothing and is gone from Available. A pack that carries even one file nothing
# above has would be seen there, so no place in this list is low enough - the
# bottom of the list is not off. That leaves Backwoods classic, Quark's
# programmer art, Simply Light's connected textures, MEGA's cell colours, the
# Bumblezone's anti-trypophobia honeycomb and the Touhou legacy sets on offer,
# along with the packs their mods build at runtime rather than ship as files:
# the Aether's two archive looks and its colourblind set, and the programmer-art
# and high-contrast variants from vanilla, Sodium, SpruceUI and Chest Tracker.
# A pack inside a mod's jar can only be kept off that screen by the mod itself,
# and Quark is the only one here that offers the switch.#
# The eight at the very bottom are there to be silent. Each is a mod's own older
# look, and every file in it is redrawn by that mod's current assets, which sit
# above. Switched on down here they change nothing, and that is the whole reason
# they are switched on: it takes them out of Available without touching how the
# build looks. Anything still on offer up there adds at least one file nothing
# above carries, so no place in this list would keep it quiet.
