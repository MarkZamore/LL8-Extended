# Every resource pack this build decides, and the order it belongs in.
#
# The order is the build. A later line sits above an earlier one where two packs
# redraw the same thing, so which of two packs is the one seen is decided here
# and nowhere else. The whole rule: the wider a pack reaches, the lower it sits.
# Stay True is the ground for every vanilla block and item, Gray's Mob Overhaul
# for every vanilla mob; the mod packs sit on those, because each speaks for one
# mod and should win where it meets a base coat; then the build's own item,
# armour and family packs; and on top the packs that redo exactly one thing.
#
# Every pack here is locked the same way, by one list: its id is named in
# enable_builtin in config/global_packs.toml, and Global Packs gives every id it
# matches the same selection - (required, TOP, fixedPosition) - so the screen
# offers neither a tick to clear nor a handle to drag. "file/" is a pack shipped
# as a file in resourcepacks/, anything else is a pack that lives inside a mod's
# jar, and nothing but that distinguishes them any more: the mod compares the
# list against each pack's own id, whatever the pack is.
#
# Naming them here is what gives them their order. A required pack the selection
# does not name is only inserted at its default position, and they came out
# alphabetical back when this file did not name them all.
#
# The two marks are the only choice this build leaves open, and they work by
# being the two ids left off that list. "?" hands an entry's on and off to the
# player and keeps only its place; "-" is the same thing shipped off. That is
# the villagers: Luigi on, Thicc off, one slot, one tick to swap.
#
# The launcher holds all of this: every launch puts these entries back in this
# order and back on, except the marked two. The player's own packs are never
# touched - not reordered, not switched off.
#
# The block before Stay True is the ground the build is painted on: what a mod
# generates or switches on for itself, and the packs that redraw only their own
# mod's blocks. These were the last entries a player could still drag about or
# switch off. Their order among themselves barely matters - nothing in the build
# redraws what they do - with one exception: tnp_resources says in its own
# pack.mcmeta that it must sit above Mod Resources, and it does.
#
# Two things are still the game's to place. vanilla is the ground under
# everything and the game keeps it there; the KubeJS packs are rebuilt every
# launch under names with commas in them, which no list of this shape can hold.
#
# What is not here is what a mod offers as an older or plainer version of
# something the build already draws - programmer art, the two archive looks of
# the Aether, SFM and Backwoods classic, Lootr's old chests, MEGA's old cell
# colours, Draconic's 2D models, the Dead King's programmer art, the
# deliberately boring Sniffer flowers - along with the accessibility variants,
# which are a different choice rather than a prettier one, and Simply Light's
# connected textures, which nothing in this build can read. Those stay in
# Available: a pack inside a mod's jar can only be kept off that screen by the
# mod itself, and Quark is the only one here that offers the switch.
