# Every resource pack the pack ships, switched on for a player who has already
# played. The launcher applies this list once per version of it: the pack's
# packs go on in this order, what the pack dropped comes off, and the player's
# own packs are never touched.
#
# Order is the game's own: a later line sits above an earlier one where two
# packs redraw the same thing. That is the whole rule this list is built on -
# the wider a pack reaches, the lower it sits. Stay True is the base coat for
# every block and item; Gray's Mob Overhaul is the base coat for every mob; the
# item and armour packs sit on those; then the packs that redo a family - baby
# animals, the four monster girls, the villagers, the cats, the llamas - and on
# top the packs that redo exactly one mob, which is why each of them is seen in
# full. The broad packs give up precisely the mobs somebody picked a
# replacement for, and nothing else.
#
# A pack shipped but missing from this list is switched off rather than left
# alone: Thicc Villagers is here in the folder and off in the selection, one
# tick away for anyone who wants it.
#
# The packs under config/paxi/resourcepacks are not named here: Paxi loads
# them itself, always and for everyone, under a name without the "file/" in
# front. A copy in resourcepacks/ next to them is one the game never sees -
# it warned "doesn't seem to exist anymore" about all five every launch.
#
# No line is marked "!". That mark put a pack into the game's own list of
# incompatible ones, and the game deselects a pack it finds in that list and
# then judges compatible - which is every pack here, because NeoForge accepts
# the older pack formats. Fifteen packs came off the selection that way; the
# game said so itself: "Removed resource pack ... from incompatibility list
# because it's now compatible".
#
# The block below the packs of the build is what the mods themselves carry:
# optional sets they ship switched off. They are named first, so they sit at
# the bottom of the selection - under every pack of the build, showing only
# where nothing above them draws anything at all.
