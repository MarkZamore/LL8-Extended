# The resource packs the build decides, and the order they belong in. The
# launcher holds this list rather than applying it once: every launch puts these
# entries back in this order and back on. The player's own packs are never
# touched - not reordered, not switched off - and what the pack dropped comes
# off.
#
# It is held because the order is the build. A later line sits above an earlier
# one where two packs redraw the same thing, so which of two packs is the one
# seen is decided here and nowhere else; a selection dragged about in the game
# is a different build until the next launch puts it back.
#
# The "# locked:" lines are the packs that moved to config/locked-resourcepacks,
# which config/global_packs.toml declares a required folder. Global Packs gives
# every pack in such a folder a selection of (required, TOP, fixedPosition), so
# the game offers neither a tick to switch it off nor a handle to drag it - the
# lock is in the game itself now, not only at the next launch. What those packs
# are called once they are forced is not "file/Name.zip" any more, and they are
# held here as comments until one launch with log_pack_ids says what it is; then
# they come back as real entries and the order is the launcher's again.
#
# The whole rule: the wider a pack reaches, the lower it sits. Stay True is the
# base coat for every block and item; Gray's Mob Overhaul is the base coat for
# every mob; the item and armour packs sit on those; then the packs that redo a
# family - baby animals, the four monster girls, the villagers, the cats, the
# llamas - and on top the packs that redo exactly one mob, which is why each of
# them is seen in full. The broad packs give up precisely the mobs somebody
# picked a replacement for, and nothing else.
#
# Two marks hand a choice back. "?" before an entry means its on and off are
# the player's; the line still says where it sits. "-" is the same thing
# shipped off. That is the villagers: Luigi is on and Thicc is off, both in the
# same slot, and swapping them is one tick in the resource pack screen.
#
# A pack shipped and not named here is switched off, not left alone.
#
# The packs under config/paxi/resourcepacks are not named here: Paxi loads
# them itself, always and for everyone, under a name without the "file/" in
# front. A copy in resourcepacks/ next to them is one the game never sees -
# it warned "doesn't seem to exist anymore" about all five every launch.
#
# No line is marked "!". That mark put a pack into the game's own list of
# incompatible ones, and the game deselects a pack it finds in that list and
# then judges compatible - which is every pack here, because NeoForge accepts
# the older pack formats. Fifteen packs came off the selection that way; the
# game said so itself: "Removed resource pack ... from incompatibility list
# because it's now compatible".
#
# The block below the packs of the build is what the mods themselves carry:
# optional sets they ship switched off. They are named first, so they sit at
# the bottom of the selection - under every pack of the build, showing only
# where nothing above them draws anything at all.
