# The resource packs this build decides, and the order they belong in.
#
# The order is the build. A later line sits above an earlier one where two packs
# redraw the same thing, so which of two packs is the one seen is decided here
# and nowhere else. The whole rule: the wider a pack reaches, the lower it sits.
# Stay True is the base coat for every block and item; Gray's Mob Overhaul is the
# base coat for every mob; the item and armour packs sit on those; then the packs
# that redo a family - baby animals, the four monster girls, the villagers, the
# cats, the llamas - and on top the packs that redo exactly one mob, which is why
# each of them is seen in full.
#
# A bare name is a pack in config/locked-resourcepacks, which
# config/global_packs.toml declares a required folder. Global Packs gives those
# a selection of (required, TOP, fixedPosition), so in the game there is no tick
# to clear and no handle to drag. Its id for such a pack is the bare file name,
# not "file/Name.zip" - that is why these lines look different.
#
# Naming them here is what gives them their order. Left unnamed they came out
# alphabetical, because a required pack the selection does not mention is only
# inserted at its default position; named, they are taken in the order given.
#
# "file/" is a pack that stays an ordinary file in resourcepacks/, and the two
# marks are the choice this build leaves open. "?" hands an entry's on and off
# to the player and keeps only its place; "-" is the same thing shipped off.
# That is the villagers: Luigi on, Thicc off, one slot, one tick to swap.
#
# The launcher holds all of this: every launch puts these entries back in this
# order and back on, except the marked two. The player's own packs are never
# touched - not reordered, not switched off.
#
# The packs under config/paxi/resourcepacks are forced the same way and are not
# named here; nothing in the build redraws what they do, so their order among
# themselves does not matter.
#
# No line is marked "!". That mark put a pack into the game's own list of
# incompatible ones, and the game deselects a pack it finds in that list and
# then judges compatible - which is every pack here, because NeoForge accepts
# the older pack formats.
#
# The block below is what the mods themselves carry: optional sets they ship
# switched off. They are named first, so they sit at the bottom of the selection.
