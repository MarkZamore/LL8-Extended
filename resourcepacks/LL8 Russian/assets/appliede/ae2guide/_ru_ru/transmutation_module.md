# Модуль трансмутации

<GameScene zoom="8" background="transparent">
  <ImportStructure src="assemblies/transmutation_module.snbt" />
</GameScene>

**Модуль МЭ трансмутации** — это ваш первый шаг к манипуляции ЭМС и алхимическим операциям внутри вашей МЭ сети. Когда модуль присоединён *где угодно* к МЭ сети, он использует знания и энергию алхимика, который его установил, и поставляет сети алхимика ЭМС как отдельный ресурс, разблокируя способность МЭ сети напрямую манипулировать этим ЭМС для трансмутации предметов в автокрафте и других связанных операциях. Эти предметы также предоставляются сети как автоматически генерируемые паттерны крафта, поставляемые модулем, с эквивалентным значением ЭМС, используемым как ингредиент крафта для каждого предмета.

![ЭМС хранилище](diagrams/emc_storage.png)

На одну сеть может быть установлено несколько модулей разными игроками, но только один модуль на одного алхимика будет вносить вклад в сохранённую цифру ЭМС и доступные предметы «для крафта». Когда на сеть установлено несколько модулей, ЭМС, поставляемый каждым модулем, собирается в один объединённый пул хранилища, монтированный на сеть только одним модулем в любой момент времени, и любой вставленный и извлечённый ЭМС будет равномерно (насколько это возможно) распределён среди всех игроков, предоставляющих ЭМС.

Модуль также включает дополнительные защиты для предотвращения проблем с переполнением в МЭ сетях, добавляя систему *уровней* для ЭМС, хранящегося в сети, на основе последующих степеней произвольно больших чисел (10^12) единиц ЭМС. Каждый уровень представлен другим цветом в сравнении с базовой единицей ЭМС и может быть «скрафчен» в более низкие уровни по мере необходимости для выполнения более требовательных работ трансмутации.

![Уровни ЭМС](diagrams/emc_tiers.png)

Однако имейте в виду, что вместе с мощью, которую предоставляет этот модуль, приходит серьёзная стандартная стоимость в энергии: 25 AE/тик, может быть больше, может быть меньше, в зависимости от конфигурации.
