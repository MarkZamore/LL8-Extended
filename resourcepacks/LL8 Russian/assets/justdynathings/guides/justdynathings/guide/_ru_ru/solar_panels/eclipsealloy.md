# Солнечная панель из сплава затмения

Солнечная панель, которая генерирует Forge Energy

Максимальная скорость FE по умолчанию: **11520**

**Условия по умолчанию:**

- Чем больше солнечных панелей рядом, тем больше они производят
- Высокий/низкий уровень Y увеличит множитель, средний уровень Y уменьшит множитель
