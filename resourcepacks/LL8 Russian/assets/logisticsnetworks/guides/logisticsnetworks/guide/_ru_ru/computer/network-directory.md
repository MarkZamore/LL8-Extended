# Сетевой каталог

Левая панель экрана компьютера. Выводит список каждой сети на сервере и позволяет выбрать, какую подключить.

![Менеджер сети с сетевым каталогом, выводящим четыре сети](../computer/images/network-manager-idle.png)

## Что показывает список

Каждая запись в каталоге показывает **имя сети** (по умолчанию буквально `Сеть` — любой другой текст означает, что кто-то её переименовал) и **количество узлов** для этой сети. Закреплённые сети получают выделенную звёздочку в верхнем правом углу записи; незакреплённые показывают тусклую звёздочку.

![Деталь одной записи сети — отмечена звёздочкой, в данный момент выбрана](../computer/images/network-entry.png)

- Префикс `>` рядом с именем отмечает запись как **выбранную** — она ещё не подключена, просто выделена. Щёлкните её снова (или щёлкните «ЗАПУСТИТЬ» / дважды щёлкните), чтобы подключить.
- Жёлтая заполненная звёздочка означает, что эта сеть закреплена (см. ниже).

## Поиск

Текстовое поле в верхней части каталога фильтрует список по совпадению подстроки с именем сети. До 32 символов. Без учёта регистра. Очистите, чтобы снова увидеть каждую сеть.

## Пагинация

На одной странице помещается только 4 записи. Нижний колонтитул показывает `1-4 / 16` — диапазон, отображаемый в данный момент, и общее количество сетей. Прокрутите колесо мыши по каталогу, чтобы пройти через остальное.

## Закрепление (отмеченные звёздочкой сети)

Щёлкните значок **звёздочки** на правом краю записи, чтобы переключить закрепление. Закреплённые сети сортируются в верхней части списка — удобно, если у вас десятки сетей и вы заботитесь только о некоторых.

Состояние закрепления хранится на блоке компьютера, а не на вашем игроке или на самой сети. Разные компьютеры могут иметь разные наборы закреплённых сетей, и если блок когда-либо сломается, закрепления сбрасываются.

## Панель неактивного сеанса

До подключения сети правая панель показывает небольшой блок помощи с тремя подсказками клавиатуры:

- **КАТ** — Просмотр сетей (это то место, где вы уже находитесь, каталог).
- **ТАБ** — Выбрать сеанс (выберите между монитором ввода-вывода и таблицей узлов после подключения).
- **ЗАПУСТИТЬ** — Открыть подсистему (перейти в выбранную подсистему).

Панель также показывает значок общего количества сетей (`16 СЕТЕЙ` на скриншоте) и индикаторы статуса (`ОЖИДАНИЕ` / `ГОТОВО`), которые загораются по мере вашего продвижения через поток.

## Подключение сети

Щёлкните запись один раз, чтобы выбрать её, затем щёлкните **ЗАПУСТИТЬ** (или щёлкните запись второй раз) для подключения. Текст неактивности исчезает, и кнопки подсистемы разблокируются. Отсюда вы можете открыть [монитор ввода-вывода](io-monitor.md) или [таблицу узлов](node-table.md).

Чтобы переключиться на другую сеть, нажмите **ВЫХОД** на странице подсистемы, чтобы вернуться в каталог, затем выберите другую.
