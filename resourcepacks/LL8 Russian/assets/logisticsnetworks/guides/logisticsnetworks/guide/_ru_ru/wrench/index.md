# Гаячный ключ

Гаячный ключ — это инструмент, который вы используете для всего, связанного с узлами — открытия их конфигурации, удаления их, копирования конфигураций между узлами и массового размещения множества узлов сразу.

Он имеет три режима, и каждый режим делает что-то другое. Циклируйте через них с **Shift + колесо мыши**, пока держите гаячный ключ. Текущий режим показан на оверлей HUD в верхней части экрана.

## Режимы в общих чертах

- [Гаячный ключ](wrench-mode.md) — по умолчанию. Откройте конфигурацию узла, удалите узлы и (с установленным AE2) переключите связь AE2.
- [Копирование / вставка](copy-paste.md) — клонируйте всю конфигурацию узла — каналы, фильтры, улучшения, метку — на другой узел. Поддерживает массовую вставку на каждый подключённый узел того же типа блока.
- [Массовое размещение](mass-placement.md) — выберите много блоков сразу, затем разместите настроенные узлы на всех них в один щелчок.

## Быстрый справочник

| Режим | Правый щелчок | Shift + правый щелчок | Ctrl + правый щелчок |
|------|-------------|---------------------|--------------------|
| Гаячный ключ | Открыть конфигурацию узла | Удалить узел (или переключить связь AE2) | — |
| Копирование / вставка | Копировать узел → буфер обмена (или открыть редактор буфера обмена на воздухе) | Вставить буфер обмена → узел | Вставить на каждый подключённый узел того же типа блока |
| Массовое размещение | Переключить блок в выборе (или открыть меню размещения на воздухе) | Тот же щелчок, что и правый щелчок | Заполнить выборку подключённого того же типа блока |

## Использование меток с гаячным ключом

Метки хорошо сочетаются с гаячным ключом. Когда вы вставляете конфигурацию на узел, метка источника также копируется — поэтому вставленный узел немедленно присоединяется к группе меток источника и остаётся синхронизированным с каждым другим узлом, разделяющим метку.

Типичный рабочий процесс:

1. Настройте один узел с конфигурацией, которая вам нужна.
2. Дайте ему метку (см. [Заголовок → установить метку](../nodes/header.md)).
3. Скопируйте его конфигурацию на буфер обмена гаячного ключа.
4. Вставьте (или массово разместите) на все другие узлы, которые должны разделять эту конфигурацию.

Каждый узел теперь носит ту же метку. Позже переделанные узлы одного из них распространяются на всю группу автоматически. Вам не нужно повторно копировать-вставлять при твиках.
