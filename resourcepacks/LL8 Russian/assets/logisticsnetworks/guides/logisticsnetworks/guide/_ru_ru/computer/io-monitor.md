# Монитор ввода-вывода

Представление живой телеметрии подключённой сети. Показывает каждый активный канал по всей сети — совокупно по индексу канала — и позволяет погрузиться в каждый для графика пропускной способности.

Откройте его из кнопок подсистемы подключённой сети. Нажмите **ВЫХОД** в верхнем левом углу, чтобы вернуться в каталог.

## Список каналов

![Список каналов монитора ввода-вывода — показывает КН0 (Предметы) и КН1 (Жидкости)](../computer/images/io-monitor-channels.png)

Каждая строка показывает один индекс канала, у которого есть хотя бы один узел в этой сети, запущенный что-то:

- **КН0** / **КН1** / ... — индекс канала (0 через 8). Совпадает с номерами слотов канала на экране узла.
- **Тип** — что передаёт канал: **Предметы**, **Жидкости**, **Энергия**, **Химикаты** или **Источник**. Окрашено в цвет типа.
- **Количество узлов** — сколько узлов в этой сети имеют этот канал включённым.

Левый край каждой строки имеет **цветную полосу**, соответствующую типу канала — зелёный для предметов, синий для жидкостей и так далее. Удобно для определения типа с первого взгляда без чтения текста справа.

Совокупность **по индексу канала**, а не по узлу. Если у вас есть 10 узлов, все запущенные передачу предметов на КН0, список показывает одну строку `КН0 Предметы 10 узлов`, а не 10 строк. Щёлкните строку, чтобы погрузиться в график.

## График пропускной способности

![График пропускной способности монитора ввода-вывода — динамические полосы КН0 с пиком около 200K/с](../computer/images/io-monitor-graph.png)

Щелчок по строке канала открывает его график. График показывает **живую шкалу времени пропускной способности передачи** для этого канала:

- **120 точек данных** всего. Каждая полоса — один образец; самая правая полоса — самая новая.
- Обновляется примерно раз в секунду по мере поступления телеметрии.
- Шкала адаптируется к пику — заголовок показывает значение пика (например `200.0K /с`) с единицей, соответствующей типу:
  - **Предметы** — предметы в секунду.
  - **Жидкости** — миллиёдра в секунду (`мБ/с`).
  - **Энергия** — Forge Energy / RF в секунду.
  - **Химикаты** — миллиёдра в секунду.
  - **Источник** — источник в секунду.
- Индикатор **ЖИВО** в нижнем левом углу загорается, когда поступают новые данные.

## Чтение графика

- Устойчивые высокие полосы = постоянная пропускная способность. Установка работает усиленно.
- Пустой график = канал существует, но передачи не происходят. Проверьте фильтры, статус и наличие ресурса в исходном блоке.
- Зубчатая картина = взрывные передачи. Обычно задержанные каналы (высокая задержка) или периодические производители.
- Внезапное падение до нуля = канал остановился (источник исчерпан, редстоун его отключил, сеть отсоединена от узла и т.д.).

Нажмите **ВЫХОД** на странице графика, чтобы вернуться к списку каналов.
