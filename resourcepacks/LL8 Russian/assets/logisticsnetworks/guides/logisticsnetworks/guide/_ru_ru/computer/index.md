# Компьютер

Компьютер — это размещаемый блок, дающий вам терминальный интерфейс для наблюдения и управления вашими логистическими сетями. Установите его в базу, щёлкните правой кнопкой мыши — и вы получите полную панель управления: список каждой сети, просмотр живой пропускной способности каждого активного канала, прямой переход к конфигурации любого узла и массовое переключение видимости узлов.

![Менеджер сети — режим ожидания без подключенной сети](images/network-manager-idle.png)

## Открытие компьютера

Щёлкните правой кнопкой мыши на размещённом блоке компьютера, чтобы открыть экран **менеджера сети**. Если у вас есть [Гаечный ключ](../wrench/index.md) где-то в инвентаре, компьютер **автоматически загружает** одну копию в слот накопителя в верхнем правом углу. Гаечный ключ одолжен, не потребляется — закройте экран, и гаечный ключ останется на компьютере, пока вы не заберёте его вручную.

Слот накопителя интерактивен только на странице сетевого каталога. Если вы переключитесь на представление монитора ввода-вывода или таблицу узлов, вы не сможете коснуться слота гаечного ключа, пока не вернётесь назад.

## Три подсистемы

После выбора сети из каталога вы можете перейти в одну из двух подсистем. Подробно рассмотрены в их собственных главах:

- [Сетевой каталог](network-directory.md) — список сетей слева; поиск, закрепление, подключение сети.
- [Монитор ввода-вывода](io-monitor.md) — совокупная пропускная способность канала с динамическими графиками (120 точек данных на канал).
- [Таблица узлов](node-table.md) — каждый узел в подключённой сети, сгруппированный по метке, с действиями в каждой строке.

До подключения сети правая панель просто показывает **Сеть не подключена**. Выберите сеть из каталога, и кнопки подсистемы разблокируются.

## Отмеченные звёздочкой сети

Каждая запись сети в каталоге имеет небольшой значок **звёздочки** справа. Щёлкните его, чтобы закрепить эту сеть в верхней части списка. Закреплённые (отмеченные звёздочкой) сети отсортированы первыми; остальные следуют. Состояние звёздочки хранится на самом блоке компьютера — сохраняется между сеансами и является отдельным для каждого компьютера (два компьютера могут иметь разные избранные).

Сети **не защищены владельцем**. Каждый компьютер на сервере может видеть каждую сеть на этом сервере, независимо от того, кто его разместил.
