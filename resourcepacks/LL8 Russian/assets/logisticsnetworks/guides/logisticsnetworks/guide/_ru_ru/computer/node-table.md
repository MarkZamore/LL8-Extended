# Таблица узлов

Представление для каждого узла подключённой сети. Выводит список всех узлов, принадлежащих сети — с типом блока, местоположением и парой кнопок действия для перехода к нему в мире или удалённого редактирования его конфигурации.

Откройте его из кнопок подсистемы после подключения сети. Нажмите **ВЫХОД** в верхнем левом углу, чтобы вернуться.

## Таблица

![Таблица узлов, показывающая четыре строки — Сундук, Бочка, Бочка, Сундук](../computer/images/node-table.png)

Каждая строка показывает один узел в сети. Столбцы:

- **Устройство** — значок предмета для блока, к которому подключен узел, плюс отображаемое имя этого блока (`Сундук`, `Бочка`, `Печь` и т.д.).
- **Местоположение** — измерение и координаты блока. Измерение использует короткий код (`ОВР` = Верхний мир, `АД** = Ад, `КОН` = Конец, пользовательские измерения показывают свой собственный короткий код). Координаты следуют как `X, Y, Z`.
- **Действия** — две кнопки значков на правой стороне каждой строки.

![Деталь строки одного узла — Сундук в Верхнем мире в 29,-60,70 с выделением + кнопками параметров](../computer/images/node-row.png)

### Действия строк

- **Выделить** (значок лампы) — переключает светящийся контур узла в мире, облегчая его поиск. Контур остаётся включённым, пока вы не щёлкните лампу снова или не закроете экран компьютера.
- **Параметры** (значок шестерёнки / терминала) — открывает полный экран конфигурации этого узла **удалённо**, откуда бы вы ни находились. Вам не нужно стоять рядом с узлом, чтобы редактировать его каналы или фильтры.

## Группировка по меткам

Узлы с меткой сгруппированы под этой меткой. Имя метки показывается как строка заголовка; щёлкните заголовок, чтобы свернуть всю группу в одну строку, щёлкните снова, чтобы развернуть. Узлы без метки отображаются плоско в конце списка.

Состояние свёрнутости запоминается за сеанс — разверните группы, над которыми вы работаете, и сверните остальные, чтобы таблица была читаема в больших сетях.

Метки устанавливаются из поля [Заголовок → Установить метку](../nodes/header.md) на каждом узле или копируются автоматически при вставке с помощью [Гаечный ключ → Копирование/вставка](../wrench/copy-paste.md).

## Массовое отображение / скрытие

Две кнопки в верхнем правом углу таблицы узлов:

- **ПОКАЗАТЬ** — включает **видимость рендера** для каждого узла в подключённой сети. Все узлы рисуются в мире с полной непрозрачностью, независимо от того, держите ли вы гаечный ключ или нет.
- **СКРЫТЬ** — **отключает видимость рендера** для каждого узла в подключённой сети. Узлы рисуются только при удержании гаечного ключа с пониженной непрозрачностью.

Для информации о том, что делает переключатель видимости для каждого узла, см. [Заголовок → Видимый](../nodes/header.md).

## Пагинация

На одной странице помещается семь строк. Прокрутите колесо мыши, чтобы пройти через более крупные сети.

## Полезно знать

- Таблица узлов активна. Узлы, добавленные, удалённые или переименованные, появляются/исчезают без необходимости повторного открытия компьютера.
- Удалённые параметры открывают полный экран узла, который вы видели бы в мире — фильтры, улучшения, каждый канал. Изменения фиксируются так же, как если бы вы стояли перед узлом.
- Контуры выделения работают на стороне клиента и видны только вам, а не другим игрокам на сервере.
