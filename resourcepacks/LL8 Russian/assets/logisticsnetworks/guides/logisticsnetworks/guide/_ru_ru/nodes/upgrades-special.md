# Специальные улучшения

Специальные улучшения не изменяют ограничения пропускной способности узла. Они разблокируют **новые возможности** — передачу между измерениями, химикаты Mekanism, источник Ars Nouveau. Каждое сидит в слоте улучшения и может быть объединено с [улучшением производительности](upgrades-performance.md) на том же узле.

Слоты улучшений находятся на панели [фильтры и улучшения](filters-upgrades.md). Дубликаты отклоняются, но разные улучшения складываются хорошо — типичный высокопроизводительный узел может содержать одно незеритовое + одно межпространственное + одно мекаизм химическое + одно ars источник.

## Межпространственное улучшение

**Разблокирует передачу между измерениями.** Без этого улучшения узел может только общаться с узлами в одном и том же измерении. Установите межпространственное улучшение, и узел может передавать в ноги и из узлов в других измерениях — между верхним миром и адом, концом и верхним миром или любым модифицированным измерением.

**Оба конца должны иметь его.** Как узел отправителя, так и узел приёмника нуждаются в установленном межпространственном улучшении. Установка его только на одну сторону недостаточна — двигатель проверяет оба узла перед тем, как разрешить переход между измерениями.

В одном измерении улучшение ничего не делает — нормальные передачи работают без него.

## Мекаизм химическое улучшение

**Разблокирует тип канала химикатов.** Без этого улучшения параметр типа на [параметры канала](channel-settings.md) не может быть установлен на химикат на узле. Установленное, узел может чувствовать и передавать химикаты Mekanism (газы, типы infuse, пигменты, суспензии) через любой канал, чей тип установлен на химикат.

Улучшение имеет значение только на узле, где настроен канал. Отправитель химикатов нуждается в улучшении; приёмник химикатов также нуждается в улучшении на своём собственном узле. Узлы, которые не передают химикаты, не нуждаются в этом.

Требует установки модификации **Mekanism** как для создания, так и для использования. Рецепт ниже появляется только при загрузке Mekanism.

## Ars источник улучшение

**Разблокирует тип канала источника.** Тот же паттерн, что и химическое улучшение Mekanism, но для источника Ars Nouveau. Установленное, узел может установить тип канала на источник и передавать источник между банками источников Ars Nouveau и любым другим совместимым с источником блоком.

Каждый узел, который передаёт источник (отправитель или приёмник), нуждается в своём собственном Ars источник улучшении.

Требует установки модификации **Ars Nouveau** как для создания, так и для использования. Рецепт ниже появляется только при загрузке Ars Nouveau.
