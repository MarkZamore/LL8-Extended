# Что такое Woot Revived?

Woot Revived добавляет многоблочную систему, которая симулирует убийства мобов и доставляет добычу прямо в ваши сундуки, без спавна самих мобов. Постройте фабрику с вашим поддельным спаунером, добавьте немного Vitality Fuel, может быть, какие-нибудь предметы для импорта, и она автоматически будет генерировать добычу в ваши сундуки.
