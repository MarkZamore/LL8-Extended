# Ingredient Importer

Ingredient Importer — это машина, которая подаёт предметы в Factory Heart для производства.

## Использование

Ingredient Importer подключается к сундукам или другим инвентарям и автоматически подаёт необходимые предметы в Factory Heart.

## Особенности

* Работает с любыми типами инвентарей
* Может подавать различные типы предметов
* Полностью автоматична

## Требуемые предметы

В зависимости от моба, Factory Heart может требовать различные предметы для производства. Ingredient Importer должна быть настроена на подачу правильных предметов.
