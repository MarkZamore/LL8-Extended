# Magmator

Magmator — это блок, который обеспечивает тепло для работы Factory Heart.

## Использование

Magmator должна быть размещена под или рядом с Factory Heart. Она необходима для работы фабрики.

## Различные уровни

Существуют Magmators для каждого уровня фабрики:

* Copper Magmator
* Iron Magmator
* Gold Magmator
* Diamond Magmator
* Netherite Magmator

## Требуемое тепло

Каждый уровень фабрики требует соответствующего уровня Magmator для работы.
