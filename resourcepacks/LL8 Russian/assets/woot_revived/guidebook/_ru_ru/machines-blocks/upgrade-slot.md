# Upgrade Slot

Upgrade Slot — это блок, в который вставляются различные улучшения для Factory Heart.

## Использование

Upgrade Slots должны быть подключены к Factory Heart. Каждый слот может содержать одно улучшение, которое будет применено к фабрике.

## Типы улучшений

Существуют различные типы улучшений:

* Rate Upgrade (ускоряет производство)
* Mass Upgrade (увеличивает количество убитых мобов за раз)
* Looting Upgrade (применяет эффект лута)
* Efficiency Upgrade (снижает расход Vitality Fuel)
* Burn Upgrade (применяет огонь к мобу)
* Decapitate Upgrade (выбрасывает головы мобов)
* XP Upgrade (выбрасывает опыт в виде осколков)
* Dimension Upgrade (изменяет измерение для некоторых мобов)

## Ограничения

Каждый уровень фабрики может содержать определённое количество upgrade slots.
