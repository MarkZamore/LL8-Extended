# Stygian Anvil

Stygian Anvil — это машина, используемая для создания различных предметов и форм Woot Revived.

## Использование

Чтобы использовать Stygian Anvil, поместите её на Magma Block и щёлкните по ней правой кнопкой мыши со Stygian Hammer.

## Требуемые рецепты

Stygian Anvil используется для создания:

* Stygian Plate (с использованием Plate Mold)
* Shard Mold (с использованием Prismarine Shard)
* Plate Mold (с использованием Iron Trapdoor)
* Dye Casing Mold (с использованием любого красителя)
* Mob Shard (с использованием Shard Mold)

## Важные заметки

* Anvil должна быть размещена непосредственно на Magma Block, в противном случае она не будет работать.
* Формы не расходуются при создании предметов.
* Вам понадобится Stygian Hammer для работы с Anvil.
