# Макет фабрики

Макет блоков фабрики важен для правильной работы. На этой странице показаны правильные макеты для каждого уровня фабрики.

## Основные правила

* Factory Heart должна быть в центре
* Primary и Secondary Fake Spawners должны быть размещены правильно
* Vitality Cell должна быть подключена к Factory Heart
* Plinth и Pylon должны окружать Factory Heart

## Примеры макетов

Различные макеты существуют для каждого уровня фабрики (Copper, Iron, Gold, Diamond, Netherite).
