# Enchanted Liquifier

Enchanted Liquifier — это машина, которая превращает зачарованные книги в Enchanted Fluid.

## Входы

* Enchanted Book Input

## Выход

* Enchanted Fluid Output

## Использование

Поместите зачарованные книги в Enchanted Liquifier и она будет производить Enchanted Fluid. Эта жидкость используется в Factory Heart для повышения уровня фабрики.
