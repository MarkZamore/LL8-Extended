# Item Infuser

Item Infuser — это машина, которая используется для создания предметов, насыщенных жидкостью.

## Входы

* Жидкость (Pure Dye Fluid, Enchanted Fluid и т.д.)
* Предмет (для инфузии)

## Выход

* Насыщенный предмет

## Использование

Item Infuser требует жидкость для работы. Она может использоваться для создания различных предметов, требующих жидкой инфузии.

## Примеры

* Glass + Pure Dye Fluid = Prism
* Книга + Enchanted Fluid = Зачарованная книга
