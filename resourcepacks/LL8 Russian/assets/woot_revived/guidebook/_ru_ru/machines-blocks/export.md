# Loot Exporter

Loot Exporter — это машина, которая выбрасывает добычу из Factory Heart в подключённый инвентарь.

## Использование

Подключите Loot Exporter к Factory Heart. Она автоматически будет вытягивать добычу из фабрики в сундуки или другие инвентари рядом с ней.

## Особенности

* Работает с любыми типами инвентарей (сундуки, барели, шалкеры и т.д.)
* Может быть подключена к нескольким инвентарям одновременно
* Полностью автоматична — не требует ручного управления
