# Fluid Infuser

Fluid Infuser — это машина, которая используется для создания различных жидкостей и предметов, насыщенных жидкостью.

## Входы

* Жидкость (для инфузии)
* Предмет (для получения жидкости)

## Использование

Fluid Infuser требует жидкость для работы. Она может использоваться для различных целей в зависимости от конфигурации мода.

## Основное использование

Fluid Infuser используется для создания топлива, зачарованных жидкостей и других жидких предметов.
