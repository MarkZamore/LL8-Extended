# Dye Liquifier

Dye Liquifier — это машина, которая смешивает различные красители в Pure Dye Fluid.

## Входы

Dye Liquifier требует четырёх входов красителя:

* Red Dye Input
* Blue Dye Input
* Yellow Dye Input
* White Dye Input

## Выход

Выход:

* Pure Dye Fluid Output

## Использование

Поместите красители в Dye Liquifier и она будет производить Pure Dye Fluid. Эта жидкость используется для создания Prism с помощью Item Infuser.
