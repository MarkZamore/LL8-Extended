# Мобы (могут вызвать задержку)

На этой странице представлены все мобы, которых можно использовать с Woot Revived.

Обратите внимание, что загрузка этой страницы может занять время, так как она содержит информацию обо всех мобах в игре.

Каждый моб имеет разный выход добычи и может иметь разные специальные требования или поведение при использовании в фабрике Woot.

Количество убийств, необходимое для программирования Mob Shard для каждого моба, также варьируется в зависимости от типа моба.
