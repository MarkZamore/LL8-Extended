# Уровни фабрики

Фабрика Woot состоит из нескольких уровней, начиная с Copper и заканчивая Netherite. Каждый уровень требует другого типа Fake Spawner и других улучшений.

* [Copper](copper.md)
* [Iron](iron.md)
* [Gold](gold.md)
* [Diamond](diamond.md)
* [Netherite](netherite.md)

Каждый уровень выше требует улучшения предыдущего уровня, поэтому вы должны строить их в порядке.

## Создание фабрики

Каждый уровень фабрики должен быть построен с использованием соответствующего Fake Spawner и Vitality Cell для этого уровня.

Layout блоков фабрики важен, и вы должны построить его правильно, чтобы фабрика работала. Обратитесь к странице [Machines/Layout](../machines-blocks/machines-blocks-index.md) для получения дополнительной информации.
