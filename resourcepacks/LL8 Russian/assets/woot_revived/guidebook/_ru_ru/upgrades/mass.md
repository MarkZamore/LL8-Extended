# Mass Upgrade

Mass Upgrade увеличивает количество мобов, убитых за одну операцию фабрики.

## Эффект

Каждый уровень улучшения увеличивает количество убитых мобов.

## Уровни

* Copper: 2x мобы
* Iron: 3x мобы
* Gold: 4x мобы
* Diamond: 5x мобов
* Netherite: 6x мобов

## Использование

Вставьте Mass Upgrade в Upgrade Slot для активации эффекта. Это позволит вашей фабрике производить больше добычи за раз.
