# XP Upgrade

XP Upgrade заставляет фабрику выбрасывать опыт в виде Mob Shards, которые можно потреблять для получения опыта.

## Эффект

Каждый уровень улучшения определяет процент убийств, при котором выбрасывается опыт.

## Уровни

* Copper: 10% XP от убийств
* Iron: 20% XP от убийств
* Gold: 30% XP от убийств
* Diamond: 40% XP от убийств
* Netherite: 50% XP от убийств

## Использование

Вставьте XP Upgrade в Upgrade Slot для активации эффекта. Опыт будет выбрасываться вместе с обычной добычей.
