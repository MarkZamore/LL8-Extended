# Burn Upgrade

Burn Upgrade применяет эффект огня к симулируемому мобу в Factory Heart.

## Эффект

При использовании Burn Upgrade мобы будут гореть в фабрике, что может повлиять на выход добычи для некоторых типов мобов.

## Использование

Вставьте Burn Upgrade в Upgrade Slot для активации эффекта.

## Особенности

* Применяется для всех типов мобов
* Не требует материала конкретного уровня
* Стоит только одного upgrade slot
