# Dimension Upgrade

Dimension Upgrade позволяет фабрике симулировать убийства мобов в определённых измерениях, что может повлиять на выход добычи.

## Типы

* Nether Dimension Upgrade (Адское измерение)
* End Dimension Upgrade (Измерение края)

## Использование

Вставьте Dimension Upgrade в Upgrade Slot для активации эффекта. Мобы будут считаться убитыми в соответствующем измерении.

## Совместимость

Некоторые мобы требуют убийства в определённом измерении для полной программирования Mob Shard.
