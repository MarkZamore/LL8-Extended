# Shard Drop Upgrade

Shard Drop Upgrade заставляет фабрику выбрасывать осколки более высокого уровня, позволяя пропустить некоторые промежуточные уровни.

## Эффект

* Iron Shard Drop: 25% шанс выбросить Copper Shard
* Gold Shard Drop: 50% шанс выбросить Iron Shard (требует Iron уровня)
* Diamond Shard Drop: 75% шанс выбросить Gold Shard (требует Gold уровня)
* Netherite Shard Drop: 100% выбросить Diamond Shard (требует Diamond уровня)

## Использование

Вставьте Shard Drop Upgrade в Upgrade Slot для активации эффекта. Это позволит вам получать более высокие уровни осколков раньше.
