# Decapitate Upgrade

Decapitate Upgrade заставляет фабрику выбрасывать головы мобов в качестве добычи.

## Эффект

Количество голов зависит от уровня upgrade (I-V). Чем выше уровень, тем больше голов выбрасывается.

## Использование

Вставьте Decapitate Upgrade в Upgrade Slot для активации эффекта.

## Уровни

* Copper: 1x голова
* Iron: 2x головы
* Gold: 3x головы
* Diamond: 4x головы
* Netherite: 5x голов
