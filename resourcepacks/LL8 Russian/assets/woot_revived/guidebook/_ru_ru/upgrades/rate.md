# Rate Upgrade

Rate Upgrade уменьшает время между операциями фабрики, заставляя её работать быстрее.

## Эффект

Каждый уровень улучшения уменьшает время обработки на определённый процент.

## Уровни

* Copper: 10% ускорение
* Iron: 20% ускорение
* Gold: 30% ускорение
* Diamond: 40% ускорение
* Netherite: 50% ускорение

## Использование

Вставьте Rate Upgrade в Upgrade Slot для активации эффекта. Это позволит вашей фабрике производить добычу быстрее.
