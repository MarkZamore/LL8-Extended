# Upgrade Base

Upgrade Base — это основной компонент для создания всех типов улучшений.

## Использование

Upgrade Base используется как основа для создания различных типов улучшений. Вы комбинируете её с различными материалами для создания специфических улучшений.

## Компоненты

После создания Upgrade Base вы можете комбинировать её с:

* Dye Plates (для Rate, Mass, Looting и Efficiency улучшений)
* Другими компонентами (для специальных улучшений)
