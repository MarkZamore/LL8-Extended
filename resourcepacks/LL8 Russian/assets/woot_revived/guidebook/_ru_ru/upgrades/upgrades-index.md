# Улучшения

Улучшения — это предметы, которые вставляются в Upgrade Slots для повышения производительности и функциональности Factory Heart.

## Основные улучшения

* [Upgrade Base](upgrade-base.md)
* [Rate Upgrade](rate.md)
* [Mass Upgrade](mass.md)
* [Efficiency Upgrade](efficiency.md)

## Специальные эффекты

* [Burn Upgrade](burn.md)
* [Decapitate Upgrade](decapitate.md)
* [Looting Upgrade](looting.md)
* [XP Upgrade](xp.md)

## Продвинутые улучшения

* [Dimension Upgrade](dimension.md)
* [Shard Drop Upgrade](shard-drop.md)

## Модульные улучшения

* [Industrial Foregoing](industrial-foregoing.md)

Каждое улучшение имеет различные уровни (I, II, III, IV, V) в зависимости от материала, из которого оно создано.
