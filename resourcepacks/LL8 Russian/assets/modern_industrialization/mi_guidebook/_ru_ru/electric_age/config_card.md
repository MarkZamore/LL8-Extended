# Продвинутая конфигурация трубопроводов

Конфигурационная плата может использоваться для маскировки трубопроводов и копирования параметров предметных труб.

<Recipe id="modern_industrialization:tools/config_card" />

Удерживание платы в левой руке автоматически применит её параметры к любой предметной трубе, которую вы поместите.
