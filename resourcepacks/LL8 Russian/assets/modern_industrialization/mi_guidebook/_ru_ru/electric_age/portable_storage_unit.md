# Переносной накопитель

Переносной накопитель (ПН) можно изготовить для перевозки энергии в своём инвентаре. Его можно заряжать и разряжать, щёлкая правой кнопкой мыши на любом накопителе энергии.

<Recipe id="modern_industrialization:electric_age/battery/portable_storage_unit_asbl" />

По умолчанию он не имеет ёмкости для хранения энергии. Чтобы добавить ёмкость, вам нужно заполнить его батареями, либо щёлкнув правой кнопкой мыши по ПН с батареями, либо щёлкнув правой кнопкой мыши по батарее с ним. Чем выше уровень батареи, тем больше ёмкости она добавит к хранилищу. Вы можете получить батарею обратно, щёлкнув правой кнопкой мыши на пустой слот, но любая избыточная энергия будет потеряна.
