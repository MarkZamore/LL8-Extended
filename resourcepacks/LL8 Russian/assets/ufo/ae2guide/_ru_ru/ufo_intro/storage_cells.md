# Ячейки высокой ёмкости хранилища

Добро пожаловать в технологию сотовых хранилищ **UFO Future**! 
Наши ячейки хранилища превосходят ванильные ёмкости Applied Energistics 2, нарушая стандартные пределы битов, чтобы удерживать астрономические объёмы материи.

Эти ячейки созданы с использованием интенсивной астрономической материи, позволяя получить экстремальные ёмкости байтов!

3. Впрыскивайте **жидкость Transcending Matter**.
