# Добро пожаловать в UFO Future

**UFO Future** расширяет эндгейм AE2 с помощью тепловых машин, звёздной материи, мегахранилищ и мультиблочной автоматизации.

![Logo](../pic/logo.png)

## Основные направления

- **DMA**: гибкая начальная продвинутая машина
- **Quantum Multiblocks**: массовая автоматизация, крафт на основе паттернов и параллельные потоки
- **Stellar Nexus**: финальная платформа симуляции для производства в экстремальном масштабе

## Новый стек мультиблоков

- **Quantum Matter Fabricator**: эволюция DMA для автоматизации AE2 и тяжёлых массовых работ
- **Quantum Slicer**: массовая подготовка печатных деталей
- **Quantum Processor Assembler**: массовая доработка процессоров
- **Quantum Pattern Hatch**: поставщик AE2 с **72-х паттернами** для линии мультиблоков

## Философия уровней

Мультиблоки используют шлюзование **MK1 / MK2 / MK3**. Более высокие уровни разблокируют лучшие рецепты и автоматически ускоряют старые.
