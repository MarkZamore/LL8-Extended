**Crafting Result Import Card** — это специализированное улучшение для **Pattern Provider**, которое упрощает автоматизацию, избавляя от необходимости в отдельных Import Bus (на блоках/механизмах, которые не могут автоматически выбрасывать предметы, как ваниллевая печь).

Эта карта позволяет самому **Pattern Provider** забирать готовые предметы обратно с соседнего механизма, эффективно объединяя логику «Push» (отправка) и «Pull» (получение) в одном блоке.

В **Pattern Provider** добавлен слот улучшения, куда можно вставить эту карту.

# Настройка
Кликните правой кнопкой мыши по предмету карты, чтобы открыть меню настроек:

*   **Import Crafting Results Only (Импортировать только результаты создания):**
    *   **Включено (по умолчанию):** Карта «умная». Она отслеживает ровно те ингредиенты, которые были отправлены, и рассчитывает ожидаемый результат. Она будет импортировать *только* эти конкретные предметы-результаты. Она игнорирует другие предметы в механизме.
    *   **Выключено:** Карта работает как обычный Import Bus. Она агрессивно забирает *любой* предмет из целевого механизма в сеть.
    *   Обратите внимание, что включение этого параметра намного дружественнее к производительности, так как ей не нужно постоянно пытаться импортировать из механизма.

*   **Sync with Crafting CPU (Синхронизация с процессором создания):**
    *   **Включено (по умолчанию):** Карта взаимодействует с процессором создания (Crafting CPU), управляющим работой. Если вы отменяете работу создания на терминале, карта прекращает ожидание результатов. Это предотвращает зависание поставщика в ожидании предметов, которые никогда не прибудут.

*   **Import Side (Сторона импорта):**
    *   **Auto (Авто):** Импортирует со стороны механизма, которая касается Pattern Provider.
    *   **Specific Side (Up, Down, North, etc.) (Конкретная сторона):** Заставляет поставщика забирать с конкретной стороны соседнего механизма. Полезно для механизмов, которые выбрасывают только на конкретные стороны (например, Sided Furnaces).


Карта использует алгоритм «экспоненциального отката» (exponential backoff). Если механизм медлителен, карта проверяет его реже, чтобы сэкономить производительность сервера. Она сразу пробуждается, когда начинается новое создание.

### Ограничения
*   **Только направленные поставщики:** Эта карта может работать как с полным, так и с версией «панель»/«часть» поставщика шаблонов. Однако полный поставщик нужно направить на конкретную сторону (можно сделать это с помощью гаечного ключа).
