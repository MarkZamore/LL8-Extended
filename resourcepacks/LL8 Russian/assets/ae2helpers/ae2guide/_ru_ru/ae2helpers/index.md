**ae2helpers** — это расширение для повышения удобства работы с Applied Energistics 2, которое делает автоматическое создание вещей гладким и компактным.

# Возможности

**1. Crafting Result Import Card**
Специализированное улучшение для **Pattern Provider**.
*   **Что делает:** Позволяет Pattern Provider **отправлять** ингредиенты на механизм и **получать** готовые результаты с той же стороны.
*   **Преимущество:** Избавляет от необходимости в отдельных Import Bus и дополнительных каналах для простых механизмов обработки.
*   Полезна только на механизмах, которые не выбрасывают свои результаты автоматически на соседние блоки.

**2. Автоматическая вставка рецептов**
Улучшенный рабочий процесс **Crafting Terminal**.
*   **Что делает:** Когда вы запрашиваете автоматическое создание рецепта в терминале, сетка переходит в состояние «ожидания» с Призрачными предметами.
*   **Преимущество:** Как только ваши CPU завершают работу, предметы **автоматически вставляются** в сетку. Больше не нужно ждать и заново кликать по рецепту!
