# Улучшение «Химикат»

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:gas_upgrade" />
</Column>

Добавляет поддержку химикатов Mekanism к DampNulls при установке Mekanism.

## Доступность

- Только DampNull
- Все уровни

## Примечания

- Только передача: нет размещения или подбора в мире
- Один химикат на слот резервуара
- Shift+щелчок правой кнопкой мыши по совместимым обработчикам химикатов для заполнения и слива
