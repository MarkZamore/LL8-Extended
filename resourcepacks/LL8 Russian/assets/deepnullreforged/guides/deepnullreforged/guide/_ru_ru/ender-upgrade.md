# Улучшение Ender

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:ender_upgrade" />
</Column>

Связывает DeepNull или DampNull с пристыкованным Null того же типа и уровня, затем отражает это пристыкованное хранилище через измерения.

## Доступность

- DeepNull или DampNull
- Все уровни

## Как использовать

1. Shift+щелчок правой кнопкой мыши по пристыкованному Null с помощью улучшения Ender, чтобы связать его.
2. Установите связанное улучшение в другой Null того же типа и уровня.
3. Установленный Null отражает пристыкованный источник, пока исходный Null не будет удалён или док не будет сломан.
