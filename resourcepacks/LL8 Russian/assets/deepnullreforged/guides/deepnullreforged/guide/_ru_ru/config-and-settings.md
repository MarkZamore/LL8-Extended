# Конфигурация и параметры

DeepNull Reforged предоставляет группы конфигурации клиента, общей и сервера, чтобы игроки и авторы пакетов могли настраивать как поведение качества жизни, так и баланс.

## Область конфигурации

- Клиент: визуальные параметры, поведение HUD, предпочтения управления и подсказки локальной интеграции
- Общее: значения по умолчанию, записанные в вновь созданные Nulls
- Сервер: переключатели геймплея, флаги включения улучшений и значения баланса уровней

## Параметры клиента

| Параметр | Что он делает |
| --- | --- |
| `showHud` | Включает наложение HUD удерживаемого null. |
| `hudOffsetX` / `hudOffsetY` | Перемещает HUD горизонтально или вертикально на экран. |
| `hudBackgroundOpacity` | Изменяет прозрачность фона HUD. |
| `hudDisplayMs` | Контролирует, как долго HUD остаётся видимым после изменений. |
| `enableShiftScrollSelection` | Позволяет `Shift + Scroll` переходить по слотам DeepNull или резервуарам DampNull циклически. |
| `invertDampNullInteraction` | Заставляет DampNulls вести себя как танки Mekanism: щелчок правой кнопкой мыши открывает GUI, а `Shift + щелчок правой кнопкой мыши` обрабатывает взаимодействие с жидкостью. |
| `enableUpdateChecker` | Включает сообщение проверки релиза, которое ссылается на страницу загрузки мода. |
| `showGuideMeHint` | Показывает подсказку GuideME при установке GuideME. |
| `animateDockedNulls` | Включает анимацию рендеринга при наведении и вращении пристыкованных Nulls. |
| `showFullDeepNullCounts` | Показывает полные сохранённые номера в GUI DeepNull вместо компактных значений стиля `1.9K` / `2M`. |

## Общие значения по умолчанию

| Параметр | Что он делает |
| --- | --- |
| `defaultTransferLocked` | Устанавливает начальное состояние блокировки передачи для вновь созданных Nulls. |
| `defaultAutoPickupEnabled` | Устанавливает начальное состояние автоподбора для новых DeepNulls. |
| `defaultAutoFeedingEnabled` | Устанавливает начальное состояние автокормления при установленном этом улучшении. |
| `defaultAutoSmeltingEnabled` | Устанавливает начальное состояние автопереплавки при установленном этом улучшении. |
| `defaultStoneworksAmount` | Устанавливает начальное значение мониторинга каменных работ для новых DeepNulls. |

## Переключатели функций сервера

| Параметр | Что он делает |
| --- | --- |
| `disableTagMatching` | Отключает сопоставление тегов словаря для фильтров DeepNull. |
| `tagBlacklist` | Блокирует использование определённых тегов для сопоставления тегов. |
| `tagWhitelist` | Если заполнено, разрешены только перечисленные теги для сопоставления тегов. |
| `enableAutoPickup` | Глобально включает или отключает автоматический подбор в совпадающие DeepNulls. |
| `enableAutoFeeding` | Включает или отключает поведение автокормления. |
| `enableAutoSmelting` | Включает или отключает поведение автопереплавки. |
| `enableCompression` | Включает или отключает поведение базового и продвинутого сжатия. |
| `enableStoneworks` | Включает или отключает обработку каменных работ. |
| `enableStoneGenerator` | Включает или отключает вывод генератора камня DampNull. |
| `enableObsidianGenerator` | Включает или отключает вывод генератора обсидиана DampNull. |
| `enableSpongeUpgrade` | Включает или отключает улучшение «Губка» DampNull. |
| `voidFullItemsOnPickup` | Если включено, автоподбор DeepNull будет по-прежнему поглощать и аннулировать совпадающие предметы, когда ёмкость совпадающего сохранённого слота уже полна. |
| `voidFullFluidsOnSponge` | Если включено, улучшение «Губка» будет по-прежнему поглощать и аннулировать совпадающие жидкости, когда совпадающий резервуар уже полон. |
| `enableChemicalStorage` | Включает или отключает поддержку хранилища и передачи химикатов Mekanism. |
| `dockGeneratorBufferSize` | Устанавливает размер скрытого буфера выходных данных дока, используемый генератором DampNulls. |

## Массивы значений уровней

Эти параметры сервера читаются в порядке уровней:

`Redstone, Lapis, Iron, Gold, Diamond, Emerald, Creative`

| Параметр | Что он контролирует |
| --- | --- |
| `itemCapacityByTier` | Ёмкость предметов DeepNull на слот. |
| `fluidCapacityByTier` | Ёмкость жидкости DampNull на резервуар. |
| `energyCapacityByTier` | Ёмкость FE для энергетического улучшения. |
| `deepEnergyCapacityByTier` | Ёмкость FE для глубокого энергетического улучшения. |
| `energyTransferByTier` | Скорость передачи FE для энергетического улучшения. |
| `deepEnergyTransferByTier` | Скорость передачи FE для глубокого энергетического улучшения. |
| `dampNullTankCountByTier` | Количество резервуаров DampNull на уровень. |
| `stoneGenerationRateByTier` | Скорость вывода генератора камня на уровень. |
| `spongeAbsorbLimitByTier` | Устаревший параметр, сохранённый для совместимости. Губка теперь поглощает все видимые блоки-источники в диапазоне. |
| `spongeRangeWidthByTier` | Размер горизонтального ящика улучшения «Губка» по уровням. |
| `spongeRangeHeightByTier` | Размер вертикального ящика улучшения «Губка» по уровням. |
