# Улучшение ведра

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:fluid_upgrade" />
</Column>

Улучшение ведра позволяет DeepNull использовать сохранённые вёдра и совместимые ёмкости жидкостей прямо из слотов предметов.

## Доступность

- Только DeepNull
- Все уровни

## Примечания

- Отдельно от DampNull, который представляет собой выделенное хранилище резервуаров
- Используется Верстаком Null для преобразования DeepNulls в DampNulls
