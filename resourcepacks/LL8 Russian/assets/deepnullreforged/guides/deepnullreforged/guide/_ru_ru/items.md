## Ссылки на предметы

- [Док-станция](docking-station.md): содержит один DeepNull или DampNull и предоставляет его для автоматизации.
- [Верстак Null](null-workbench.md): обрабатывает рецепты верстака с сниженной стоимостью, синхронизацию и стилизацию.
- [Синхронизатор](synchronizer.md): хранит снимок конфигурации Null для резервного копирования и восстановления, может быть очищен в руке или сетке крафта.
- [Фильтр](filter-item.md): компонент для крафта улучшения фильтра.
- [Ядро улучшения](upgrade-core.md): общий компонент для крафта большинства улучшений.
- [Ядро улучшения Ender](ender-upgrade-core.md): компонент для крафта улучшения Ender.
