# Верстак Null

<Column alignItems="center" fullWidth={true}>
  <BlockImage id="deepnullreforged:null_workbench" />
</Column>

Верстак Null — это выделенный блок для специального крафта Null, резервного копирования и восстановления синхронизатора, а также настройки стиля.

## Вкладки

- Craft (крафт): рецепты верстака со сниженной стоимостью
- Sync (синхр.): копирование или восстановление конфигурации Null через синхронизатор
- Style (стиль): настройка цветов рамки и стекла

## Примечания

- Автоматизация по умолчанию используется только на стороне крафта
- Вывод стиля появляется в правом слоте вывода
- Sync использует два больших слота слева для ввода и два больших слота справа для вывода
- Копирование и восстановление занимают 3 секунды и возвращают Null плюс синхронизатор на правую сторону
- Рецепты верстака DeepNull используют предмет уровня, блоки угля, стекло и соответствующий краситель
- Рецепты верстака DampNull используют DeepNull того же уровня и улучшение ведра
