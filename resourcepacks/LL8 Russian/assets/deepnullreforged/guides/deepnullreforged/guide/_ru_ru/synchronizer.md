# Синхронизатор

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:synchronizer" />
</Column>

Синхронизатор хранит снимок конфигурации Null, чтобы его можно было восстановить в другой совместимый Null через Верстак Null.

## Что он хранит

- Параметры фильтра
- Параметры конфигурации улучшений
- Переключатели передачи и поведения
- Другие данные конфигурации Null

Он **не** копирует сохранённые предметы, жидкости, химикаты или энергию.

## Использование

- Вставьте Null в левый входной слот и синхронизатор во второй левый слот вкладки Sync Верстака Null
- Нажмите **Back Up** (резервное копирование), чтобы сохранить конфигурацию Null в синхронизаторе
- Вставьте свежий совместимый Null плюс сохранённый синхронизатор и нажмите **Restore** (восстановление), чтобы применить сохранённые параметры
- Обе действия занимают 3 секунды и возвращают Null плюс синхронизатор в два больших слота вывода справа

## Очистка

- Shift+щелчок правой кнопкой мыши в воздухе с настроенным синхронизатором, чтобы очистить его
- Поместите настроенный синхронизатор самостоятельно в любую сетку крафта, чтобы очистить его
