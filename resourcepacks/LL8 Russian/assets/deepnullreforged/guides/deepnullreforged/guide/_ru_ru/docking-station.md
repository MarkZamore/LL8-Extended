# Док-станция

<Column alignItems="center" fullWidth={true}>
  <BlockImage id="deepnullreforged:deepnull_dock" />
</Column>

Док-станция содержит один DeepNull или DampNull и предоставляет его для автоматизации.

## Возможности

- Автоматизация предметов для пристыкованных DeepNulls
- Автоматизация жидкостей для пристыкованных DampNulls
- Автоматизация энергии для пристыкованных DeepNulls с энергетическим улучшением
- Автоматизация химикатов для пристыкованных DampNulls с улучшением «Химикат»

## Примечания

- Пристыкованные генератор DampNulls используют буфер дока для вывода сгенерированных предметов
- Улучшения Ender могут связываться с пристыкованными Nulls через измерения
