# Terminal Settings

Myotus добавляет вкладку с простыми настройками на экран «Настройки терминала» AE2.
Здесь также можно управлять настройками модов, связанных с Myotus.
<FloatingImage  src="../assets/myotus_tab.png" align="right"/>

## Параметры

<Translate key="gui.myotus.checkbox.show_upgrade_panel_button" bold="true" /> определяет, будет ли кнопка на панели инструментов терминала открывать панель улучшений Myotus.

<Translate key="gui.myotus.checkbox.show_view_cell_slots.only" bold="true" /> определяет, будет ли панель улучшений терминала показывать второй столбец для слотов ячеек просмотра AE2. Этот
параметр работает на Minecraft 1.21.1. На Minecraft 1.20.1 параметр отключён и помечен как доступный только для 1.21.1.


## Настройки клавиш
Настройки клавиш, установленные на этой странице, синхронизируются с привязками клавиш Minecraft.  
По умолчанию настройки клавиш терминала работают только, когда терминал открыт.
## Открыть настройки терминала

Клавиша: <KeyBind id="key.myotus.open.terminal_setting" />

Открывает экран настроек терминала с вкладкой Myotus.

## Переключить панель улучшений терминала

Клавиша: <KeyBind id="key.myotus.toggle.upgrade_terminal_panel" />

Открывает или закрывает панель улучшений терминала Myotus с экрана терминала.
